# Cocos Capital

Cocos Capital is an Argentine investech and online broker (ALyC, founded 2021 in Buenos Aires) offering a 100% digital investment platform for retail investors — Argentine stocks, CEDEARs, bonds, mutual funds, the MEP dollar, US stocks, and crypto. Regulated by Argentina's CNV and settling through the BYMA group, Cocos has surpassed 300,000 accounts.

Surfaced as a portfolio lead of 500 Global and enriched by the API Evangelist pipeline.

- Website: https://cocos.capital
- App: https://app.cocos.capital

Note: Cocos Capital publishes no official public API or first-party SDK. The only client library found (pyCocos) is unofficial and community-built.
